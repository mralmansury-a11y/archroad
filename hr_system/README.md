# نظام إدارة الموارد البشرية — إدارة خدمات الطريق الدولي
Flask + SQLite (الحزمة الوحيدة المطلوبة: Flask)

## التشغيل السريع
**ويندوز:** انقر مرتين على `run.bat`  
**يدوياً:**
```bash
python -m venv venv
venv\Scripts\activate          # لينكس/ماك: source venv/bin/activate
pip install -r requirements.txt
python seed.py                 # ينشئ قاعدة البيانات + بيانات تجريبية (يحذف أي بيانات موجودة!)
python app.py                  # ثم افتح http://127.0.0.1:8000
```

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `hoda.hr` | `Hr@12345` | موارد بشرية |
| `admin` | `Admin@12345` | مسؤول نظام (يرى صفحة المستخدمين ويحذف الموظفين) |

## الوحدات
| الوحدة | الوظائف |
|---|---|
| لوحة التحكم | مؤشرات حيّة، حضور 7 أيام، توزيع الإدارات، قبول/رفض الإجازات، عقود قريبة الانتهاء |
| الموظفون | بحث وفلترة، إضافة، تعديل، ملف شامل، حذف (للمسؤول) |
| الحضور | سجل يومي (حضور/انصراف/غياب/إجازة)، تسجيل الجميع، تقرير شهري |
| الإجازات | طلبات مع تحقق من الرصيد السنوي (30 يوماً)، قبول/رفض (يُسجَّل في الحضور تلقائياً)، إلغاء |
| الرواتب | إنشاء كشف الشهر (خصم الغياب تلقائياً)، مكافآت/خصومات، اعتماد الدفع، قسيمة للطباعة، تصدير CSV |
| الأداء | تقييم بأربعة معايير ونسبة إجمالية وتصنيف |
| التوظيف | وظائف شاغرة، لوحة مرشحين بمراحل، التعيين ينشئ ملف موظف تلقائياً |
| التدريب | دورات، تسجيل بحد أقصى للمقاعد، إتمام الدورة |
| مستندات الموظفين | رفع جواز السفر والرقم الوطني والصورة الشخصية وعقد العمل (PDF / JPG / JPEG / PNG، حتى 5 ميجابايت للملف) من صفحة ملف الموظف، عرض وتنزيل وحذف |
| المستخدمون | إنشاء/حذف حسابات، إعادة تعيين كلمة المرور، وكل مستخدم يغيّر كلمته من «حسابي» |

## الهيكل
```
app.py        التهيئة + الدخول + لوحة التحكم     core.py   دوال مشتركة وصلاحيات وCSRF
db.py         اتصال SQLite                         schema.sql / seed.py
modules/      ملف مستقل لكل وحدة (employees, attendance, leaves, payroll, performance, recruitment, training, users, documents)
templates/    قوالب Jinja (مجلد فرعي لكل وحدة)     static/   css + js + img (الشعار)
```

## مستندات الموظفين
- تُحفظ الملفات في `instance/uploads/<رقم الموظف>/` بأسماء عشوائية، خارج مجلد `static`، ولا تُعرض إلا لمن سجّل الدخول.
- يُتحقق من الامتداد ومن محتوى الملف الفعلي (لا يكفي تغيير الامتداد)، والصورة الشخصية تقبل JPG وPNG فقط.
- حذف الموظف (للمسؤول) يحذف ملفاته أيضاً. **خذ نسخة احتياطية من مجلد `instance/` كاملاً** (قاعدة البيانات + المستندات).
- إن كانت لديك قاعدة بيانات قائمة فلا حاجة لتشغيل `seed.py`: جدول المستندات يُضاف تلقائياً عند تشغيل التطبيق دون المساس بالبيانات.

## ملاحظات
- **الأمان:** حماية CSRF على كل نماذج POST، وكلمات المرور مُشفّرة. قبل الاستخدام الفعلي عيّن مفتاحاً سرياً:  
  ويندوز `set SECRET_KEY=قيمة-طويلة-عشوائية` ثم شغّل التطبيق، وغيّر كلمات المرور التجريبية. وأوقف `debug=True` في `app.py` على الخادم الفعلي.
- **الخطوط:** تُحمَّل من Google Fonts؛ بدون إنترنت يستخدم النظام خطوط الجهاز تلقائياً.
- **العطلة الأسبوعية:** الجمعة والسبت (يمكن تغييرها من `WEEKEND` في `core.py`).
- **الاستضافة على IIS:** استخدم `wfastcgi` أو `waitress` (`waitress-serve --port=8000 app:app`).
